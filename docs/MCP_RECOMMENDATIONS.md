# MCP / Plugin Recommendations — Arkein

Recommended tooling for safe AI-assisted development.

## P0 — Essential
- **Context7 MCP** — current library/API docs (Astro 5, Tailwind CSS v4). `npx -y @upstash/context7-mcp`.
- **Playwright MCP** — browser visual smoke tests. `npx -y @playwright/mcp@latest`.
- **Gitleaks CLI** — secret scanning. `gitleaks detect --source . --verbose`.

## P1 — High value
- **Fetch MCP** — fetch public docs.
- **Semgrep** — SAST scanning.
